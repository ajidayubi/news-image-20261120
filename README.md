This repository contains a self-contained TypeScript program that generates a comprehensive newspaper front page summarizing the world news of Friday, 20 November 2026. The lead story features the historic trilateral peace declaration signed by Trump, Xi, and Putin in Shenzhen following APEC talks, alongside coverage of the International Court of Justice ruling on Myanmar, Anthropic's landmark $2 trillion IPO on Nasdaq, the escalating cost of US operations in Iran, European-led peace talks for Ukraine, and Taipei's stock market plunge. The image is rendered entirely through procedural pixel drawing and encoded directly into a byte-identical, deterministic PNG asset with zero external dependencies or network calls.

## Run it with
```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
